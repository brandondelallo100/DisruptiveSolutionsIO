# Disruptive Solutions I/O website (final, October 25, 2026)

Static one-page site. No build step, database or server code. Prepared by InnovatePM Solutions.

## Files
- `index.html`: the page, with title, description, social-share tags and structured data for search and AI assistants
- `styles.css`, `script.js` (mobile menu only)
- `assets/`: hero banner, headshot, badge logo, favicon, and the Barlow Condensed headline font (SIL Open Font License, `assets/fonts/OFL-LICENSE.txt`)

## Deploy
1. Upload the whole folder to any static host (Netlify, Vercel, Cloudflare Pages or GitHub Pages; free tiers fit the under-$50/month budget).
2. Point disruptivesolutions.io to the host. **Change only the website records (A/CNAME).** Leave the MX and email records alone so bjd@disruptivesolutions.io keeps working.
3. Turn on HTTPS at the host.
4. After launch, check the share preview with LinkedIn's Post Inspector. The share image uses https://disruptivesolutions.io/assets/hero-banner.jpg.
